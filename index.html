Setup Checklist

  1. 1
    Connect to the machine
    Plug the LumenPnP in over USB, then connect.
  2. 2
    Import a job or gerber files
    Load a saved job, or import gerbers to start a new one.
  3. 3
    Set the board's rough position
    Jog to each fiducial, then to the board surface, so the machine roughly knows where the board sits.
  4. 4
    Calibrate on the fiducials
    Auto-centers the camera on each fiducial to precisely locate the board.
  5. 5
    Calibrate the nozzle offset
    Optional, but recommended after swapping tips - aligns the dispense tip with the camera's view.
  6. 6
    Review dispense & extruder settings
    Check dispense degrees, speeds, and Z offsets before running.
  7. 7
    Export or run the job
    Save the job for later, or run it now.

Extruder Settings

Global Settings

Cross-cutting paste-dispense settings that apply across every pattern and every board in this job. The per-pattern classification thresholds and placement settings live on the Grid/Line/Staggered tabs; per-board nozzle offsets live in the Job Positions panel.

Line (Elongated Pad) Dispense Settings

Which pads count as elongated (get a line of dots instead of a single dot), and how that line is placed. Changing a value immediately re-runs the currently loaded board's pads through the new setting - no need to re-import the gerber. Note: this resets any per-pad enable/disable selections back to all-enabled, since a settings change can change how many dots a pad even has.

Solder Paste Grid Settings

Which pads count as a large open pad (e.g. a QFN thermal pad - gets a grid of dots instead of one dot/line), and how that grid is placed. Changing a value immediately re-runs the currently loaded board's pads through the new setting - no need to re-import the gerber. Note: this resets any per-pad enable/disable selections back to all-enabled, since a settings change can change how many dots a pad even has.

Staggered / Tight-Pitch Dispense Settings

Which pads count as fine-pitch/tight-pitch (TSOP/QFP/SOIC-style gull-wing leads sitting in a tight row - get a single staggered dot instead of a line), and how that dot is placed. Changing a value immediately re-runs the currently loaded board's pads through the new setting - no need to re-import the gerber. Note: this resets any per-pad enable/disable selections back to all-enabled, since a settings change can change how many dots a pad even has.
