Tunes how a gerber import turns pad footprints into dispense dots (see gerberImport.js). Changing a value immediately re-runs the currently loaded board's pads through the new setting - no need to re-import the gerber. Note: this resets any per-pad enable/disable selections back to all-enabled, since a settings change can change how many dots a pad even has.
