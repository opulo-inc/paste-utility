LumenPnP Pasting Utility - Instructions

Introduction

This utility is designed to support automatic paste dispensing jobs on the LumenPnP with the Paste Extruder Toolhead. It supports running jobs based on a Gerber export from your ECAD software, or by manually capturing positions with the toolhead for other applications. Gerber-based jobs can even facilitate machine vision based fiducial calibration. Jobs can be saved and re-imported later, with all calibration and per-board offset data included. A job can hold several boards at once (each gets its own tab), and running a job pastes every board in one go. To use this utility, you will need:

  • A LumenPnP
  • A Paste Extruder Toolhead (either the original V1 Beta syringe-plunger version, or the current V2 auger version - see "Choosing your hardware version" below)
  • The paste you'd like to dispense (we strongly recommend GC50 for solder paste applications)
  • An appropriately sized luer lock tip (we recommend a 22 gauge tip for most PCB applications)
  • The PCB (or other substrate) you'd like to apply paste to, attached to the LumenPnP's staging plates
  • If loading a PCB job:
    • The Paste and Mask layer gerber files for the side of the PCB you'd like to paste (a single zip of your fab output works too - the importer auto-detects which files are which). This has been tested with KiCAD exports only thus far.
    • The PCB has three, 1mm diameter fiducials.

Choosing your hardware version

The very first time you open this page, you'll be asked to pick which Paste Extruder you're running: Paste Extruder V1 Beta (the original syringe-plunger dispenser) or Paste Extruder V2 (the current auger-based dispenser). This choice determines how dispense G-code is generated, so the rest of the app stays hidden until you pick one. Your choice is remembered in this browser, so you won't be asked again - but you can change it any time from the dropdown next to the page title at the top. Switching versions doesn't require reloading a job; it just changes what happens the next time paste is actually dispensed.

The Setup Checklist

The panel at the very top of the page walks through the same steps described in detail below, in order, as a quick reference: connect, import, set rough position, calibrate on fiducials, calibrate the nozzle offset, review settings, then export or run. Each step's button just triggers the matching control described in this document - it doesn't do anything different. A step greys out (with a tooltip explaining why) until its prerequisite is done, e.g. you can't set a rough position before importing a board with exactly 3 fiducials.

Connecting to the LumenPnP

  1. Make sure your LumenPnP is connected to your computer via the top camera cable, and the USB data cable from the motherboard.
  2. From the drop-down in the top right, select the Top Camera, then click "Connect". If you don't see the top camera, reconnect the camera and then reload the page.
  3. Select the LumenPnP serial port in the pop-up window and click "Connect".
  4. You should now see the camera feed in the panel on the right. Underneath it, "Camera Scale (px/mm)" and "Fiducial Confidence" control how fiducial jogging and detection interpret that feed - retune Camera Scale if you swap cameras/lenses/focus height, and lower Fiducial Confidence if real fiducials aren't being found (or raise it if silkscreen/pads are being mistaken for fiducials).
  5. With the Z gantries level, click the Home X, Home Y, and Home Z buttons.
  6. Try jogging the machine around using the jog buttons and the distance slider beneath them.
  7. A few other controls in that panel:
    • "Jog to Fid in View" finds a fiducial in the camera feed and jogs to it - handy for quickly centering the camera reticle on a fiducial.
    • "Visual Home" jogs the camera to the datum board, finds the homing fiducial, and resets the machine's position based on it. Do this at the start of every session to make sure previously-calibrated job positions are still valid.
    • Clicking a location in the camera feed jogs the machine to that position - a quick way to center the view on a feature.
    • "Extrude" runs the paste extruder motor directly, without moving anything else - useful for priming the extruder or testing "Invert Dispense" (see below) before a real run.
  8. Below the jog controls: Ring Lights, Left/Right Air, Left/Right Vac, and Disable Steppers toggle those machine functions directly, and the Console at the bottom lets you send raw G-code and see the machine's responses - handy for troubleshooting.

Job Setup from Gerbers

  1. Click "Import Gerber" (in the Setup Checklist, or the Job Positions panel) and select your paste + mask gerber files, or a single zip of your fab output. Paste, mask, and board outline layers are detected automatically from file content - you don't pick which file is which.
  2. The board view below the Job Positions list will populate: red dots are paste points, blue dots are fiducial candidates found on the mask layer, and a grey outline (if present) traces the board edge.
  3. If the mask layer yielded at least 3 fiducial candidates, that's it - fiducials are picked automatically. If fewer than 3 were found, you'll be prompted to click FID1, FID2, then FID3 yourself in the board view; a picked candidate turns green. (You can also add fiducials manually later with "Capture New Position" - see below.)
  4. The Job Positions list now shows every pad, grouped by component type (Resistors/Capacitors/ICs/Other) and then by component - click a group header to expand it. Each group has a checkbox to enable/disable every pad under it for the run; individual pads have their own checkbox too, and clicking a pad's dot directly in the board view toggles it the same way (a disabled pad draws as a dim hollow circle instead of a solid one, so it's still there to click back on).
  5. To paste more than one board in the same job, click the "+" tab next to the board name before importing the next board's gerbers - each tab is a fully independent board with its own placements, fiducials, calibration, and nozzle offset. Don't switch tabs (or start another import) while a rough-position/fid-cal/nozzle-cal step below is still waiting on you - the app will refuse and tell you to finish or cancel it first, since doing so mid-step could otherwise apply that step's result to the wrong board.
  6. Click "Get Rough Board Position" (Setup Checklist step 3, or the Job Positions panel). As instructed by the panel at the bottom of the page, jog the camera to be centered on FID1, then FID2, then FID3, clicking the panel's button to confirm each. Finally, jog the paste extruder nozzle tip so it's just barely touching the top surface of the board, and confirm. This gives the machine an approximate idea of where the board and its fiducials are, and stamps a starting Z height (nozzle-contact height) onto every fiducial.
  7. The pad positions in the Job Positions list update to reflect this rough placement. Click the circle "move to" icon on any entry to jog the machine there and sanity-check the alignment.
  8. If one side of the board sits higher or lower than the rest (a board that isn't perfectly flat, or is warped), you can fine-tune this without redoing the whole rough-position step: each fiducial's row has an editable Z field - nudging one fiducial's height re-fits a tilt plane across every pad's Z, instead of every pad sharing one flat height.
  9. Click "Perform Fid Cal". This jogs to each fiducial's rough position and uses the camera to precisely center on it, replacing the rough alignment with an accurate one. This is required before a run - "Run Job" will refuse to start (with a message naming the board) if a board with enabled pads hasn't had this done yet. If it isn't finding fiducials reliably, try adjusting the Fiducial Confidence slider under the camera feed, or re-check the rough positions.
  10. Click "Nozzle Offset Cal" (also in the Job Positions panel - note this is per-board, so it's worth re-checking after switching tabs or swapping tips). As instructed, jog the camera to be centered on any fiducial, confirm, then jog the nozzle tip so it's perfectly centered on and touching that same fiducial, and confirm again. The resulting offset (and the X/Y/Z Offset readout/adjustment buttons just above the board tabs) belongs to whichever board tab is currently active.
  11. Review the dispense/extruder settings (Setup Checklist step 6 links straight to this): Dispense Degrees and Invert Dispense are on the Basic tab of the Extruder Settings panel (Retraction Degrees and Dwell Milliseconds also show up there, but only for Paste Extruder V1 Beta - V2's auger doesn't use them); Motion Speed, Extruder Speed, Pasting Motor Current, Air Assist, Travel Height, and Pre/Post-gcode are on the Global tab, since they apply across the whole job rather than one pattern. The Grid/Line/Staggered tabs tune how differently-shaped pads (large open pads, elongated pads, tight-pitch rows) get their own dot patterns automatically - changing a value there re-runs the currently loaded board's pads through it immediately, no re-import needed.

Job Setup from Captured Positions

  1. Jog the nozzle tip to the first location you'd like to dispense paste, at the exact height you want it to dispense at.
  2. Click "Capture New Position" (in the Job Positions panel) - a new position appears in the list, added to whichever board tab is currently active, at exactly the machine's current X/Y/Z.
  3. Repeat until you've captured every position you'd like to dispense paste at.
  4. A captured point is already a real machine position, not a gerber design-space one, so it doesn't need the fiducial-calibration transform gerber-imported pads get. If the same board tab also has gerber-imported pads that DO need "Nozzle Offset Cal" and fiducial calibration, those still apply to this board as a whole - a captured point's own position just isn't affected by them.
  5. Note: re-running "Get Rough Board Position", "Perform Fid Cal", or editing a fiducial's Z field afterward will re-fit that board's Z-tilt plane across every pad on it, captured points included - so a captured point's height isn't necessarily permanent if you go recalibrate the board afterward.

Import/Export

Once you've completed setup (Gerber-based, captured, or a mix), export the job to run later: click "Export Job" (Setup Checklist step 7, or the Export/Run panel) and save the file. In a new session, click "Import Job" to load it back in. A saved job includes every board tab (not just whichever one was active when you saved), each board's own calibration and nozzle offset, and every setting on the Basic/Global/Grid/Line/Staggered tabs. Your hardware version choice (V1 Beta vs V2) is not part of the job file - it's remembered per-browser instead, since it describes which machine you're running, not the job. The job file is plain JSON, so it's easy to inspect or hand-edit if you'd like to make your own adjustments.

Running a Job

With a job loaded and calibrated, click "Run Job" (Setup Checklist step 7, or the Export/Run panel). Before doing so, it's worth priming the extruder with the "Extrude" button in the jog panel - otherwise it can take a while for paste to actually start flowing once the run begins. If any board with enabled pads hasn't had "Perform Fid Cal" completed, the run will refuse to start and tell you which board(s) still need it, rather than dispensing at rough/uncalibrated positions.

A run pastes every board tab in the job, one after another, in a single pass - not just whichever tab happens to be open. While running, a toast at the bottom of the page shows the job is in progress; closing it cancels the run and parks the machine safely. Air Assist and Pasting Motor Current (Global settings tab) can be adjusted live while a run is in progress, and take effect on the very next point.
